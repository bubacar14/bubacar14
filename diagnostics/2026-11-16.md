- Clarity, source facebook : 299 sessions, 293 visiteurs distincts, sur 3 jours. C'est presque exactement les 293 vues de Meta. **Hypothèse** (forte) : ces sessions sont presque toutes la page parents. Le script ne sépare pas par page, donc non vérifié.
- Ces visiteurs restent peu : 66 s de présence dont 11 s actives, défilement moyen 33 % de la page (**vérifié**, Clarity). La plupart ne lisent pas jusqu'au bout.
- Clics « Envoyer à mon enfant » et « Essayer moi-même » : **non disponibles** (les événements `parents_envoyer_*`, `parents_essayer_*`, `parents_lu_*` sont dans Clarity mais `diagnostic.mjs` ne les lit pas). À regarder à la main dans Clarity.

## Causes probables
1. **La page parents fait lire mais pas agir** (hypothèse appuyée par les chiffres). 293 visiteurs, 33 % de défilement moyen, 11 s actives, 4 passages dans l'appli. À confirmer avec les événements Clarity de clic.
2. **Trafic à bas prix, peu qualifié** (hypothèse). 0,03 $ la vue et 37 198 impressions pour 8,76 $ : les gens touchent, regardent, et ne s'engagent pas. La même chose a été vue avec la pub du 28/10.
3. **Le parcours dans l'appli s'effondre dès l'entrée** (vérifié). 88 % ne finissent pas l'accueil ; en version C, 0 sur 5 finit l'équation. Trop peu de monde pour conclure, mais pas de signe d'amélioration. Le code de `renderDemo` (`app.js`, ligne 495) mesure `demo` début, étapes et fin : on pourra voir l'étape où ils lâchent quand il y aura plus d'élèves.
4. **Navigateur de Facebook** (vérifié par Clarity : tout le trafic a la source facebook). Dans ce navigateur, la mémoire de l'appareil n'est pas retrouvée ailleurs ; la carte « Ouvrir dans Chrome » a été ajoutée le 13/11, mais on ne sait pas encore si elle est cliquée.
5. **Erreurs de script** (vérifié, à creuser) : 5 % des sessions facebook (15 sessions, 17 erreurs). Clics morts : 4,35 % des sessions (161 clics). Un seul cas de clics de rage (135 clics dans une session, probablement un seul appareil). Impossible de dire si c'est la page parents ou l'appli.
